# Software

- Unity Engine
- Blender 3D Modelling

Our team using Unity as the engine to build this game, because Unity more easily, quickly, and familiar for our team.

Besides that our team using Blender for making 3D model like Character, Environment, and other stuff which need it to make.

# About The Game

The game will have a horror theme where the MC has just moved into a new house which looks old and a bit dirty.

- In Macro Loop Mc have to solve the puzzle about OOP in Java languange, but Mc cant easily to solve that puzzle because he got interferenced by somethings.

- In Micro Loop Mc must done the mini game, which's like do some little things on each stuff in the Micro Loop.
